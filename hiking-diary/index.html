나는 오늘도 등산을 합니다 — 개인정보 처리방침

시행일: 2026년 9월 6일

이 앱은 회원가입이 없고, 개발자에게 전송되는 개인정보가 없습니다.

사용자가 남긴 산행 기록은 기기에 저장되며, iCloud에 로그인되어 있는 경우 Apple의 iCloud를 통해 사용자 본인의 계정 안에서만 동기화됩니다. 개발자는 이 기록에 접근할 수 없습니다.

1. 수집하는 개인정보

이 앱은 개인정보를 수집하지 않습니다.

회원가입, 로그인, 이메일 주소 입력 절차가 없습니다. 이름, 연락처, 위치 정보, 연락처 목록, 사진을 요구하지 않으며 접근 권한도 요청하지 않습니다.

광고 식별자를 사용하지 않고, 분석 도구(SDK)를 넣지 않았으며, 사용 기록을 개발자 서버로 보내지 않습니다. 개발자가 운영하는 서버 자체가 없습니다.

2. 사용자가 앱에 남기는 기록

앱을 쓰는 동안 사용자가 직접 입력하는 내용입니다. 개인정보가 아니라 사용자 본인의 기록이며, 아래에 무엇이 저장되는지 밝힙니다.

  • 오른 산 (앱에 내장된 산 목록에서 고르거나, 목록에 없으면 직접 입력한 이름)
  • 산이 속한 시군구 (목록에서 고른 산이면 자동으로 정해지고, 직접 입력한 산이면 선택 항목입니다)
  • 산행 날짜
  • 만족도
  • 메모 — 선택 항목이며, 남기지 않으면 저장되지 않습니다

위치 정보(GPS)는 사용하지 않습니다. 산행 날짜와 산 이름은 사용자가 고르는 값이며 앱이 위치를 추적하거나 확인하지 않습니다.

이 기록은 사용자가 앱 안에서 언제든 수정하거나 삭제할 수 있습니다.

3. 저장되는 곳

기기 안
기록은 먼저 사용자의 기기 안에 저장됩니다.
iCloud (사용자 본인의 계정)
기기에 iCloud가 로그인되어 있으면, 기록은 Apple의 CloudKit 프라이빗 데이터베이스를 통해 사용자 본인의 iCloud 계정으로 동기화됩니다. 같은 Apple 계정을 쓰는 사용자의 다른 기기에서 같은 기록을 볼 수 있습니다.
  • 이 저장 공간은 사용자 본인의 iCloud 용량을 사용합니다
  • 개발자는 이 데이터에 접근할 수 없습니다. 프라이빗 데이터베이스는 사용자 본인의 계정으로 보호되며, 앱 개발자에게 조회 권한이 없습니다
  • 다른 사용자와 공유되지 않습니다
  • iCloud에 로그인하지 않았거나 iCloud를 꺼둔 경우, 기록은 기기 안에만 저장되며 앱은 그대로 동작합니다

iCloud에 저장된 데이터의 취급은 Apple의 개인정보 처리방침을 따릅니다.
https://www.apple.com/kr/legal/privacy/

4. 제3자 제공

제공하지 않습니다. 기록을 판매·대여·공유하지 않으며, 광고나 분석 목적으로 제3자에게 전달하지 않습니다.

이 앱에는 광고가 없고, 외부 분석 도구를 넣지 않았습니다.

5. 보관 기간과 삭제

기록은 사용자가 지울 때까지 보관됩니다. 보관 기간 제한을 두지 않습니다.

  • 개별 기록 삭제 — 앱 안에서 기록을 열고 "기록 지우기"
  • 기기에서 전체 삭제 — 앱을 삭제하면 기기에 저장된 기록이 함께 지워집니다
  • iCloud에서 삭제 — iOS 설정 > [사용자 이름] > iCloud > 저장 공간 관리에서 이 앱의 데이터를 지울 수 있습니다

앱을 지워도 iCloud에 동기화된 기록은 남아 있을 수 있습니다. 완전히 지우려면 위의 iCloud 설정에서 함께 삭제해야 합니다.

6. 사용자의 권리

기록은 사용자의 기기와 사용자 본인의 iCloud 계정에 있으므로, 열람·수정·삭제를 개발자에게 요청할 필요 없이 직접 하실 수 있습니다. 개발자는 해당 데이터를 보유하고 있지 않아 대신 조회하거나 삭제해 드릴 수 없습니다.

7. 아동의 개인정보

이 앱은 개인정보를 수집하지 않으므로 아동으로부터도 개인정보를 수집하지 않습니다.
